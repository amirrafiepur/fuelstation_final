{% comment %} Shared keyboard navigation for report tables (no mouse needed). Included by گزارش کارکرد هر نازل and لیست اطلاعات فروش. Enter toggles table-navigation mode: the first row of `rowsSelector` is highlighted in blue; ArrowDown/ArrowUp move the highlight (clamped to the first/last row) and the page scrolls to keep the selected row in view; Enter again leaves the mode and removes the highlight. Outside table mode, ArrowUp/ArrowDown are handed to the optional `onArrowOutsideTableMode(event)` callback (the nozzle ledger uses it for nozzle selection); with no callback they keep their normal browser behaviour. Enter does nothing except toggle the mode, and only when there is a table row to navigate. Every key is ignored while the user is typing in or operating a control (input, select, textarea, button, link, editable element) and when Ctrl/Alt/Meta is held, so normal keyboard behaviour elsewhere on the page is never affected. Usage (after the table, which needs class="row-nav-table"): TableRowNavigation.init({ rowsSelector: '#my-table tbody tr', hintId: 'table-mode-hint', // optional element shown in table mode onArrowOutsideTableMode: function (e) { ... } // optional }); {% endcomment %}
