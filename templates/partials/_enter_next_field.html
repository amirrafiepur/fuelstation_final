{% comment %} Enter-to-next-field for data-entry forms (minimize mouse usage). Included once by base.html; a form opts in with the attribute data-enter-next. * Enter in any field except the last moves focus to the next field in form order (and selects its content, like Tab does, so a pre-filled value can be typed over). * Enter in the last field submits the form exactly as the submit button would (form.requestSubmit with the form's own submit button), so required-field/validation behaviour is unchanged -- an invalid form stays on the page and the browser points at the problem. * Optional fields may stay empty: Enter simply moves past them. * Fields are inputs and selects that are visible, enabled and editable; hidden/readonly/disabled inputs, checkboxes, radios, files and buttons are skipped. Textareas keep Enter as a new line. * Never active outside a marked form: tables, filters, links, buttons and every other page element keep their normal Enter behaviour, and the Enter-driven table navigation (partials/_table_row_navigation.html) ignores keys pressed inside form fields, so the two never collide. * Shift/Ctrl/Alt/Meta+Enter, IME composition and key auto-repeat are left alone or swallowed safely (a held Enter can neither skip through the form nor submit it repeatedly). Written as one delegated listener so it works for however many fields a form has, in whatever order, and never needs updating when fields change. {% endcomment %}
